# Changelog

## 0.1.0 — 2026-08-24

First public release of Eidos Paseo Plugin Store.

- Public `catalog.json` and plugin tarballs behind GitHub `releases/latest/download/` URLs that do not change.
- `install.sh` installs the store onto an existing Paseo daemon.
- Store UI can install and update catalog plugins from those tarballs.
