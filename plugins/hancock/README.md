# Hancock

Human signing desk for [Hancock](https://github.com/eidos-agi/eidos-paseo-plugin-store) on this Paseo.

Agents queue with `hancock add`. You sign here. Runtime id: `hancock`.

```bash
paseo plugin install /absolute/path/to/eidos-paseo-plugin-store/plugins/hancock
```

Or install from the public catalog via Eidos Plugin Store.

⌘K → **Open Hancock**. Approve / deny / skip bind as `human@paseo`.
